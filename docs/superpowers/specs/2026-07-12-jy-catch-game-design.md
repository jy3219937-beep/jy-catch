# 정율 캐치(JY-Catch) — 캠 손동작 학습 게임 설계

작성일: 2026-07-12
프로젝트 위치: `/Users/sunghyunji/개발/jy-catch`

## 1. 개요

정율사관학원 이벤트(부스)용 **캠 손동작 게임**. 학생이 자신의 폰으로 QR을 찍어 신청하면,
카메라가 달린 메인 기기에서 순서대로 한 명씩 게임을 진행한다.

캠 영상이 배경으로 선명하게 보이는 위로 학습 관련 "용어 물체"가 떨어지고,
학생은 손동작(손바닥→주먹 집기)으로 학습에 **도움이 되는 용어**를 집어 점수를 얻는다.
학습을 **방해하는 용어**(유튜브·릴스 등)를 집으면 감점된다.

최종 점수를 "달성 등급"으로 환산하고, 달성 등급에 따라 "서강대 ○○학과 합격!" 메시지와 함께
순위(리더보드)에 등록한다. 순위는 게임 중에도 화면 우측에 상시 노출된다.

교육 메시지: **유혹(SNS)은 흘려보내고, 학습 도구(질문·튜터링)는 적극적으로 붙잡아라.**

## 2. 아키텍처

두 종류의 클라이언트 + 공용 백엔드 서버.

```
┌────────────────────┐         ┌─────────────────────┐
│  학생 폰 (신청)      │         │  메인 기기 (게임)     │
│  /join             │         │  /  (게임 앱)        │
│  QR로 접속 → 신청폼  │         │  캠 + 손인식 + 게임   │
└─────────┬──────────┘         └──────────┬──────────┘
          │                                │
          │        ┌──────────────┐        │
          └───────▶│  Next.js API  │◀───────┘
                   │  + SQLite(Prisma)     │
                   │  신청 / 대기열 / 순위  │
                   └──────────────┘
```

- **스택:** Next.js (App Router) + API Routes + SQLite(Prisma ORM). 기존 `instagram`/`qbank` 프로젝트와 동일 패턴.
- **손 인식:** MediaPipe Tasks Vision `GestureRecognizer` (CDN 로드, 온디바이스). `hand-gesture/index.html`의 로직을 재사용.
- **실시간성:** 부스 규모(동시 소수)이므로 polling(2~3초 간격)으로 충분. WebSocket 미도입(YAGNI).
- **운영 구조:** 메인 기기 1대(카메라+큰 화면) + 학생 각자 폰. 신청 순서대로 한 명씩 진행.

## 3. 데이터 모델 (Prisma / SQLite)

```
Player (신청 = 대기열 항목이자 참가자)
  id            String   @id
  name          String
  school        String
  grade         Int      // 학년 (1/2/3)
  currentTier   Float    // 현재 등급 (예: 2.0)
  targetTier    Float    // 목표 등급 (예: 1.3)
  status        String   // "waiting" | "playing" | "done"
  createdAt     DateTime // 신청 시각 (대기 순서 기준)

GameResult (게임 종료 후 기록 = 리더보드 항목)
  id            String   @id
  playerId      String   // Player 참조
  name          String   // 순위 표시용 (비정규화)
  school        String
  finalScore    Int
  achievedTier  Float    // 달성 등급
  department    String   // 매핑된 서강대 학과명
  difficulty    Float    // 계산된 난이도 계수 D (기록/분석용)
  createdAt     DateTime
```

## 4. 화면 흐름

### A. 학생 폰 — 신청 페이지 `/join`
- QR로 접속.
- 입력: 이름 · 학교 · 학년 · 현재 등급 · 목표 등급.
- 제출 → `Player` 생성(status="waiting") → "대기번호 N번, 앞에 M명 대기 중" 표시.
- 자기 순서가 되면(폴링) "곧 당신 차례입니다" 안내.

### B. 메인 기기 — 게임 앱 `/`

**B-1. 대기 화면**
- 큰 QR 코드(신청 링크) + 현재 대기열 목록 표시.
- 맨 앞 대기자 정보 카드(이름·학교·학년·현재/목표 등급) 표시.
- 관리자가 학생 확인 후 **👍 엄지척 제스처를 확인 영역에 일정 시간(예: 1.2초) 유지**하면 게임 시작.
  (마우스/터치 없이 손만으로 진행 — 부스 운영 편의)

**B-2. 게임 화면 (핵심)**
- **배경: 캠 영상을 선명하게 전체 배경으로 렌더링(거울 모드).** 학생이 자기 모습을 보며 플레이.
  - (참고: `hand-gesture/index.html`은 캠을 alpha 0.12로 흐리게 깔지만, 게임에서는 선명하게 전면 표시)
- 그 위에 오버레이 레이어:
  - **상단 HUD:** 스테이지(N/5) · 점수 · 남은 시간 · **실시간 달성 등급**(점수 변화 시 즉시 환산 갱신) · 콤보 게이지.
  - **떨어지는 용어 물체:** 도움용어(초록 계열) / 방해용어(붉은 계열)가 위에서 아래로 낙하.
  - **손 골격 오버레이:** 21개 랜드마크 스켈레톤.
  - **우측 패널:** 🏆 TOP5(이름·달성등급·합격학과) + "내 현재 예상 순위". 그 아래 **신청 QR 코드**.
- **조작:** 손바닥→주먹(집기) 제스처로 손 위치에 겹친 용어를 집음.
  - 도움용어 집기 → **+점수** + 파티클 폭발 모션(물방울 튀김, 별, 점수 팝업).
  - 방해용어 집기 → **-감점** + 붉은 실패 이펙트 + 화면 흔들림.
  - 도움용어를 놓쳐 바닥에 떨어지면 무득점(감점 없음). 방해용어는 무시하면 안전(0점).

**B-3. 결과 화면**
- 최종 점수 → 달성 등급 환산 결과.
- "**서강대 ○○학과 합격!**" 큰 메시지.
- 이번 게임으로 획득한 순위 표시.
- `GameResult` 저장.

**B-4. 순위 화면**
- 전체 리더보드(달성 등급 높은 순).
- 각 순위 항목에 이름·달성등급·**합격 학과** 표시.
- 일정 시간 후 대기 화면으로 복귀(다음 학생).

## 5. 게임 규칙 상세

| 용어 종류 | 집었을 때 | 놓쳤을 때(바닥) |
|-----------|-----------|-----------------|
| 🟢 도움용어 (질문·답변·튜터링·복습·오답노트 등) | **+점수** | 무득점 |
| 🔴 방해용어 (유튜브·릴스·인스타그램·숏츠·게임 등) | **-감점** | 안전(0점) |

- 집기 판정: 손 랜드마크가 용어 물체 영역과 겹친 상태에서 손바닥→주먹 전환 감지 시 "집음".
- 콤보: 도움용어 연속 성공 시 점수 배율 상승(방해용어 집으면 콤보 리셋).

## 6. 난이도 로직 (내부 계산)

```
올려야 할 양   = currentTier - targetTier        (예: 2.0 - 1.3 = 0.7)
남은 학기 수   = 학년 기반 계산                    (사용자 예시: 1학년 → 4학기 남음)
학기당 부담    = 올려야 할 양 / 남은 학기           (예: 0.7 / 4 ≈ 0.175)
난이도 계수 D  = 학기당 부담을 정규화한 값           (0~1 범위로 스케일링)
```

- D가 클수록(목표가 빡셀수록) 게임이 어려워진다. 아래 4요소가 **균형 있게** 함께 상승:
  1. 낙하 속도 ↑
  2. 방해용어 비율 ↑
  3. 동시 등장 개수 ↑
  4. 목표 점수선(클리어 기준) ↑
- 한 요소만 극단으로 가지 않도록 각 요소는 완만한 곡선으로 D에 연동.

### 스테이지 (5단계)
- 스테이지 1→5로 갈수록 스테이지 배율 S가 상승.
- 실제 난이도 = 기본값 × (D 반영) × (스테이지 배율 S). 뒤 스테이지일수록 어려워진다.

## 7. 등급 환산 & 학과 매핑

- **점수 → 달성 등급:** 목표 점수선을 기준으로 한 환산 곡선(고득점일수록 낮은=좋은 등급).
- **달성 등급 → 서강대 학과:** `등급구간 → 학과명` 매핑 테이블.
  - **초기: 임시(placeholder) 표로 구현.** 예:
    ```
    1.0 ~ 1.2  → (학과 A)
    1.3 ~ 1.5  → (학과 B)
    1.6 ~ 1.8  → (학과 C)
    ...
    ```
  - **이후 사용자가 제공하는 실제 서강대 합격 컷라인 데이터로 이 표만 교체.** (매핑은 단일 설정 파일로 분리해 교체 용이하게)

## 8. 제스처 정리

| 상황 | 제스처 |
|------|--------|
| 게임 시작 확인(대기 화면) | 👍 엄지척(Thumb_Up)을 확인 영역에 일정 시간 유지 |
| 용어 집기(게임 중) | 손바닥(Open_Palm) → 주먹(Closed_Fist) 전환 |

## 9. 범위 밖 (YAGNI)

- WebSocket 실시간 통신(폴링으로 충분).
- 계정/로그인(이벤트 일시 사용).
- 다기기 간 게임 진행 동기화(메인 1대 고정).
- 사운드는 있으면 좋으나 필수 아님(2차).

## 10. 열린 항목

- 서강대 학과 매핑 실제 데이터(사용자 제공 예정) — 그 전까지 임시 표 사용.
- 용어 목록(도움/방해)의 최종 문구 세트 — 초기 기본 세트 제공 후 조정.
- "남은 학기 수" 정확한 계산식 — 사용자 예시(1학년 → 4학기)를 기준으로 구현 시 확정.
  (학년별 남은 학기 매핑을 명시적 상수 테이블로 두어 조정 용이하게)
